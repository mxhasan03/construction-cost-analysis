# 🏗️ Construction Cost Analysis Dashboard

## 📊 Overview
This project analyzes construction project costs by comparing approved budgets against actual spending. The goal is to identify high-risk projects, major cost drivers, and category-level budget overruns.

## 🧠 Key Insights
- Project **P008** is the highest-risk project, with multiple categories exceeding budget.
- **MEP and structural components** are the largest cost drivers.
- Several categories are classified as **At Risk** or **Over Budget**.

## 🛠️ Tools Used
- SQL (MySQL)
- Tableau

## 📂 Project Structure
- `sql/` → data queries and transformations
- `excel/` → processed datasets
- `dashboard/` → visualization and screenshot
